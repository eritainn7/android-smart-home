app - мобильное приложение для подключения устройств умного дома.

auth - сервис авторизации.

api-smart-home - сервис, который должен работать с группами устройств умного дома и самими устройствами умного дома, так же должен получать данные в реальном времени от устройств через mosquito mqtt(Homie Convention??) и отдавать их мобильному приложению в реальном времени.

esp8266 - пример-прошивка устроства, которое измеряет температуру.

# Cервис авторизации

1. POST /auth/reg (подтверждение через код 6-значный на почту) - Регистрация
2. POST /auth/login - Вход
3. POST /auth/logout - выход из системы
4. DELETE /auth/login - Удаление аккаунта
5. PUT /auth/login - Обновление данных аккаунта
6. POST /validate

	Redis хранит email и хэш кода подтверждения при попытке регистрации, а также отозванные jwt-токены(срок жизни токена 5 минут). Email+хэш кода подтверждения удаляются при подтверждении пользователем почты и добавления учётной записи в Postgres; отозванные jwt удаляются при истечении их срока действия.

	Postgres сервиса авторизации хранит учётные записи пользователей

		
# API умного дома

Postgres хранит группы устройств, созданные пользователем, и устройства, добавленные в эти группы.
Необходимо, чтобы между Mobile и API умного дома происходил обмен данными с устройств в реальном времени. Данные с устройств получаем из mosquito mqtt (протокол Homie Convention), причём данные в брокер отправляют устройства умного дома.

# ESP8266
На базе данного микроконтроллера разработано устройство измерения температуры, с последующим выводом на дисплей. Необходимо в прошивку добавить небольшое веб-приложение для задания параметров подключения к mosquito и wi-fi. Также необходимо предусмотреть WebView в мобильном приложении, чтоб кофигурировать esp. Для устройства можно задать локальный домен для упрощения подключения.
